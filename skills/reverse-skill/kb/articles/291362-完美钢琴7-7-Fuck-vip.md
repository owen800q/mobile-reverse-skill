突然对钢琴来了兴趣，看到网上用的都是完美钢琴比较多

一打开发现各种插件和乐谱都要VIP？作为白嫖党怎么能忍得了这些（dog）
我寻思上网找个7.7的免VIP，发现没有一个是有用的。。。。。。

直接在jadx的c5.b类搜Z方法 （寻找方法就不多废话了 这主要还是给想用这款软件的人提供方法）

```
public static boolean Z(Context context)
```

![image](https://bbs.kanxue.com/upload/attach/202605/1014889_XKKR44TY8J5ANH8.webp)

public static boolean Z(Context context) {

    o(context);  // 初始化 SharedPreferences

    return f3057b.getBoolean("p_m_s", false);     ***//`false=不是vip ; true=是vip`***

}

储存`SharedPreferences`

默认存false，直到服务器下发为tru e

那还废话啥 直接patch 修改 Z() 方法smali 永远返回true

原：

```
.method public static Z(Landroid/content/Context;)Z
    .registers 3

    .line 1
    invoke-static {p0}, Lc5/b;->o(Landroid/content/Context;)V

    .line 2
    .line 3
    .line 4
    sget-object p0, Lc5/b;->b:Landroid/content/SharedPreferences;

    .line 5
    .line 6
    const-string v0, "p_m_s"

    .line 7
    .line 8
    const/4 v1, 0x0

    .line 9
    invoke-interface {p0, v0, v1}, Landroid/content/SharedPreferences;->getBoolean(Ljava/lang/String;Z)Z

    .line 10
    .line 11
    .line 12
    move-result p0

    .line 13
    return p0
.end method
```

改：

```
.method public static Z(Landroid/content/Context;)Z
    .registers 2
    const/4 v0, 0x1
    return v0
.end method
```
