# apphub站点介绍

本期推荐一个自己做的一个apk下载公益站点 [apphub](https://apphub.x1a0f3n9.top/ui/)，先说说有啥用吧

1. 国内各应用商店apk直链提取
	- 指纹分析中的channel有用，做指纹分析建议动起来，可以不动但是为什么要留弱点呢，等着被综合聚类一波端么;
	- 我一直认为想要大批量设备注册的话要藏木于林的，不是说对方不验证这东西就没用的，这点我相信每个人能够根据自己的场景来选择;
	- 方法就是用我这个网站下载各个渠道的，然后抓包分析变化，或者更简单的是分析apk目录结构找到一个chanel相关的文件，然后提取出来之后就好了;
2. 多渠道历史版本apk直链提取
	- 指纹分析必备的，因为一般核心sdk也是有版本的，这个版本是随着app版本固定的，可能会作为一部分指纹，如果你永远是一个版本或者不一致，等着被综合聚类一波端么
	- 不止豌豆荚，还有应用汇这个站点也是有历史版本，不过相对少得多
3. 新版本监测 邮箱提醒（需登录）
	- 例如某书，一周1-2次更新，你想要业务长期稳定就跟着动起来吧
4. 64位/32位探测
	- 豌豆荚经常32位，用得多的朋友都知道，这个点很傻逼，我的暴论就是：arm32这种东西就应该赶紧淘汰，初学者学了纯浪费时间
	- 这里我的做法是下载apk尾部的部分字节，然后提取出zip的目录，观察lib/; 因为我不想服务器提前下载好apk,这样会浪费我服务器带宽（毕竟公益站点，能省就省....
5. 反馈广场
	- 有啥要加的功能/反馈都可以提，我会定期处理
	- 比如国外的站点如google play还有 我知道的十几个镜像站
	- 如果反馈的很重要的话，可以微信交流群艾特我

# 心路历程

2. 本来打算开源的，结果逆向过程中发现了各种指纹sdk, 如果开源出来纯找死了，包括但不限于某讯，某里，所以自己留着用吧
3. 我星球的朋友经常有这个下载64位apk还有其他应用商店的需求
4. 豌豆荚web端已经下线了搜索界面，但是后端接口还在，目前可以使用我的开源工具[wandoujia-downloader](https://github.com/LunFengChen/wandoujia-downloader)进行大批量下载，但是我预计后续接口也会被下架。
5. 正在逆向豌豆荚app层的直链提取，后面逆向完了会作为兜底使用，如果app下载的也多是64位我会把web接口作为兜底
