# 0x2 修改frida

>
> 先把所有的 "frida_agent_main" 换成"main"
>
>
>  ![图片描述](https://bbs.kanxue.com/upload/attach/202412/957122_4ANF7RP243J5DVZ.webp)
>
>
>

>
> 然后直接git am打上patch, 如果不会打的话其实一个个改也不费事，因为核心其实在python脚本，和前面的字符串处理
>
>
>

>
> 我这里把frida改成了rusda，你也可以改成其他的
>
>
>  ![图片描述](https://bbs.kanxue.com/upload/attach/202412/957122_D448S2HNAW33K6J.webp)

>
>
>
