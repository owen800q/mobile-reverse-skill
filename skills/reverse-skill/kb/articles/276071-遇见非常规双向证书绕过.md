# 最终

利用hook到的值去全局搜索即可得到被调用的证书以及证书的key。在burpsuit中的User options 》 TLS中导入相对于的证书与域名即可。

# 其他

在证书存在于本地的资源文件中，对证书名进行加密和去掉证书后缀。导致常规的全局搜索找不到证书的所在，若是证书通过远程进行下载，以及存在这样的情况下如何去解决。
