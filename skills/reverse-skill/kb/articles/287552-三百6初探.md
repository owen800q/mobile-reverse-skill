    翻译成解密脚本:

\```
import idaapi
import idc
from ida_tools import get_text_segment_range

def decode():
    text_start, text_end = get_text_segment_range()
    v1 = 0x34b0
    v2 = 0x1c098
    v3 = v1

    idc.patch_byte(text_end - 1, idaapi.get_byte(text_end - 1) ^ (v1 + v2))
    i = 0x1C098
    while i != 1:
        v11 = (v3 + i)
        v12 = idaapi.get_byte(v3 + i - 1)
        v13 = idaapi.get_byte(v3 + i - 2)
        i -= 1
        idc.patch_byte(v11 - 2, v13 ^ v12)

decode()
\```

like_decode_so如下:

![image](https://bbs.kanxue.com/upload/attach/202508/696771_9BZ29V3ZP9K9Y4G.webp)

由 ((*(__int64 (__fastcall **)(rawEncodeData *))(encode->some_fun + 24))(encode) & 1) != 0 )// 0x035938这一行将内部so地址传入,调用一个小型vmp解密解压数据, 再将解密数据传入下图的loadso函数:

![image](https://bbs.kanxue.com/upload/attach/202508/696771_CB2QASBR9E9MN9N.webp)

decode_data    函数将so的program header和其他两个什么链接相关的表头解密

prelink_image  这个函数可以参考源码中的链接的那个函数将switch中的结构体补全

do_relocation   这个函数执行重定位

loadso执行完成后, 返回上层函数like_decode_so,最后调用init系列函数
