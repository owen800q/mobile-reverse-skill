\```
// 0x52 标志是否已经修复了B指令
// X0: &start
// X1: 解压后的大小，0xADA6C
while(X1--) {
//判断是否是B指令
    int ins = [x0 + x1 * 4];
    if (ins >> 26 != 5) {
        continue;
    }
    [x0 + x1 * 4] = (ins - x1) & 0x3FFFFFF | ins & 0xFC000000
}
\```

简单来说就是修复offset
![image](https://bbs.kanxue.com/upload/attach/202607/995540_QAP85C32ZJ6RWE3.webp)
这里给出的内存映射大小是0x98C84,实际大小应该是&start + 0xADA6C = 0xEFFE0 需要ida 重新设置segments, 进行patch即可修复so层代码
