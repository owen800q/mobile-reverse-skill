# 1.        分析环境

分析工具：IDA, JEB, Jadx

分析设备：雷电模拟器

系统版本：Android 9

# 2.        需求

## 2.1.       游戏有隐藏行为，动态加载了dex，满足一定条件后会打开一个web网址

样本类型：游戏

分析需求：1、找到条件并进入; 2、解密加密文件

# 3.        解答过程

## 3.1.       找到访问的web网址, 并访问

根据清单文件可以定位到主活动, 如下图所示:

![image](https://bbs.kanxue.com/upload/attach/202509/998608_AR455B2E49D2REJ.webp)

查看主活动后,发现其中并没有什么有用的信息, 如下图所示:

![image](https://bbs.kanxue.com/upload/attach/202509/998608_7SNRD3XRACNT5YT.webp)

猜测是否重写了CocosActivity 类; 查看CocosActivity类可以发现其中重写了很多方法, 其中onCreate方法尤为值得注意,其中调用了onLoadNativeLibraries方法与onCreateNative方法,如下图所示:

![image](https://bbs.kanxue.com/upload/attach/202509/998608_CZ5TV2TJS2QBXXC.webp)

onLoadNativeLibraries方法中手动加载了libcocos.so文件,并给Intent中传入了一个参数, 供GameActivity类使用, 如下图所示:

![image](https://bbs.kanxue.com/upload/attach/202509/998608_NZBB7VA99A3QX96.webp)

onCreateNative是一个 native 方法, 所以通过压缩软件可以在SheepWalking-release.apk\lib\arm64-v8a\文件夹下获取到 libcocos.so文件, 使用ida可以查看其具体代码, 如下图所示(为提供可读性代码, 所示代码为F5后的代码):

![image](https://bbs.kanxue.com/upload/attach/202509/998608_NBQED8JKT5YFBED.webp)

onCreateNative中主要做了如下几步操作:

1.         初始化ClassLoader

2.         检查手机的日期是否在2024/07/17 - 2024/07/23范围内(图中的checkSystemTimeValidity 函数, 未导出 ), 若是则执行游戏逻辑, 否则

3.         检查当前手机是否在印度的加尔各答地区 ( 图中的checkForIndiaRegion 函数, 未导出 ), 若不是则执行游戏逻辑, 否则

4.         通过反射来初始化一个com/gtoanaf/appfase/WAP类, 并调用其中的gotian方法来打开 ”<https://www.baidu.com/>” 网页

结论:

       若要在程序启动时访问的是上述网页, 则可通过如下方法

1.         修改手机时间不要修改为2024/07/17 - 2024/07/23范围内(最好设置为当日日期, 否则可能无法正常访问网页), 并将手机时区修改为加尔各答, 然后重启手机后打开程序就会直接访问上述网页;

2.         通过hook的方式修改校验函数的返回值, 直接返回true 即可;

3.         通过hook的方式修改手机时间和时区, 以满足程序所需的校验;

## 3.2.       解密加密文件

分析Java_com_cocos_lib_CocosActivity_onCreateNative 函数不难看出, 加载网页前调用了一个函数(图中的decodeAndroidJs 函数, 未导出):
