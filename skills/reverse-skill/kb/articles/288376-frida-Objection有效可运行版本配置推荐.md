之前frida环境搞坏了。重新安装倒比较快。但是Objection因为时间长了，对新的环境不太兼容。所以就找老版本配置折腾了很久。

现在把最终可用的环境配置发出来。

我的环境：你们有其他的版本组合也可以留言，有需要的按照最小版本改动去改。

```
MacOS 15.5
Android 14
Python 3.9.10
frida 16.2.1
frida-tools 12.3.0
objection 1.11.0
```

再简单说一下安装方法。以下是Mac上的流程。

因为Objection需要低版本python，所以使用了pyenv做python版本管理。

```
安装pyenv
brew update && brew install pyenv

在zshrc添加环境
# pyenv 配置
echo 'export PYENV_ROOT="$HOME/.pyenv"' >> ~/.zshrc
echo 'command -v pyenv >/dev/null || export PATH="$PYENV_ROOT/bin:$PATH"' >> ~/.zshrc
echo 'eval "$(pyenv init -)"' >> ~/.zshrc
让环境生效
source ~/.zshrc

安装一个稳定版本，需要一段时间
pyenv install 3.9.10

然后进入frida工作区（为了让python3.9只在工作区生效）
cd /proj/frida

设置工作区使用3.9
pyenv local 3.9.10 (搞错目录使用pyenv local --unset还原)

当前工作区下做一个新的python环境
python -m venv frida-venv
source frida-venv/bin/activate

最后是神圣的时刻，安装我推荐的版本。这个frida版本我换了不知道多少个了。最后试出来这个可以用。
pip install frida-tools==12.3.0 frida==16.2.1 objection==1.11.0

然后其他的warn你们去deepseek去问吧，不影响使用。
```
