## 简单描述

整体基于新版frida的zymbiote机制，但是做了创新，不能说是完全无痕吧，但是企业壳，银行啥的都随便注入，如果注入之后闪退了，那极大概率是你注入的so做了什么，被检测到了

## 使用方法

右下角 -> 选择你要注入的app -> 输入你要注入的so的路径(绝对路径) -> apply
主页最后一个卡片的左下角的按钮点了可以复制我的微信号，有什么问题可以和我反馈
以后会在这里更新：https://github.com/SoyBeanMilkx/funny
