##   tvmAsm to Asm

  这里拿个比较简单的举例 ADRP [vm] fun: 0xD0A88, opcode: 05000000

![image](https://bbs.kanxue.com/upload/attach/202309/927003_42CDMSNB2ZTJ4CG.webp)

  对arm汇编熟悉的人那么不难看出来，这个handler内部解析opcode执行对应操作，实际上就对应一条arm64指令。我的还原方法是通过观察arm64-v8a解析opcode的方式，与反汇编操作进行对比，以判断是否相符。

![image](https://bbs.kanxue.com/upload/attach/202309/927003_MY8GUEB996BG2GZ.webp)

  把sub_D0A88代码还原出来和[arm64(ADRP)编码](http://hehezhou.cn/isa/adrp.html)对比一样，由此判定该方法为ADRP。

| 1234567891011121314 | `void` `sub_D0A88(uint64_t opcode, uint64_t ctx) {``// integer d = UInt(Rd);``uint32_t Rd = opcode & 0x1f;` `// imm = SignExtend(immhi:immlo:Zeros(12), 64);``uint64_t imm = (0x3fff & ((opcode >> 0x11) & 0x3000)) \| ((0x3ffff & (opcode >> 5)) << 0xe);` `uint64_t PC = *(uint64_t*)(ctx + 0x108);``// bits(64) base = PC[]; base<11:0> = Zeros(12);``uint64_t base = (PC & 0xfffffffffffff000);` `// 写回寄存器 X[d] = base + imm``*(uint64_t*)(ctx + (Rd << 3)) = base + imm;``}` |
