协议定义：

```
syntax = "proto3";

package MSSdk;

message MSSeedResponse {
    string seed = 1;
    ExtraInfo extra_info = 2;
}

message ExtraInfo {
    string algorithm = 1;
}
```

get_seed 协议的返回字段 algorithm 用于标记参数签名中的加密算法，通过测试发现该字段有 8 种不同的值，分别对应有 8 种加密方式。

用于参数签名的字段中，字段 24 是 协议返回的seed值，字段 26 是 extra_info加密字段， 其中 字段 1 决定了加密算法，也就是协议返回字段的algorithm值：

![image](https://bbs.kanxue.com/upload/attach/202506/770147_C5GPVU638U4V9ZG.webp)

我们可以发现这个加密值长度始终是 12 个字节。
