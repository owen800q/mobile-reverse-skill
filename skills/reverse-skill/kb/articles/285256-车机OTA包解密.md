唉，一言难尽，我的良马（ju）车机系统终于更新了，上了想要的功能，福音呀，盼了很久，终于更新了。

我就想着将OTA包里面的apk，直接提取出来，升级就行了，不需要更新车机系统了，结果失败！

拿到了心心念的OTA升级包，一打开。

哦豁~~~~

![image](https://bbs.kanxue.com/upload/attach/202501/857508_B4PY8WJ7TBT87WV.webp)

它竟然做了加密的，，，好惨

我就想着，既然这里做了加密，那么车机系统在拿到包后，肯定也需要进行解密才能去安装呀，于似乎带着好奇去看了看

# 0x1 获取升级apk

在车机交流群里面，顺利拿到了负责车机升级的apk，拖进jadx 里面，找关键字，HuOs

还真找到了。

 ![image](https://bbs.kanxue.com/upload/attach/202501/857508_C5N8AXSMP5CBT5Z.webp)

这不就是我升级的路径，和包格式嘛 .zip

跟着调用栈一路静态分析，结果追到了解密方法：

 ![image](https://bbs.kanxue.com/upload/attach/202501/857508_RGAMAJAXACTY3W3.webp)

这里发现 包被进行了 "AES/CBC/PKCS5Padding" 的加密，车机系统拿到文件，进行解密后，再安装

# 0x2 获取解密Key

又上一个步骤发现，是通过获取 "ckey" 的值，

然后使用 解密，对这个文件进行解密，获取前16 字节，作为系统包的aes key

 ![image](https://bbs.kanxue.com/upload/attach/202501/857508_ZMF3HXY5SZ24JYY.webp)

想要解密这个就得两个步骤：

1、获取到这个ckey 这个文件 （万能的车友群 把文件给了我）

2、拿到 decrypt 的代码实现逻辑 （万能的车友群 把文件给了我）

步骤2 走了一些弯路

起初以为 decrypt 这个代码的实现是放在 boot-framework.vdex 、最后通过搜索，发现是放在

 boot-ext.vdex 里面的。

 ![image](https://bbs.kanxue.com/upload/attach/202501/857508_RRKG66EVQ944PDB.webp)

这里就需要使用两个工具

1. vdex 转为cdex
2. 再将 cdex 转为dex

最终打开，

 ![image](https://bbs.kanxue.com/upload/attach/202501/857508_FMYJSJ6CCVPM2A9.webp)

解密方法则是将 文件的值，与一个key ，进到native 里面 计算出来

 ![image](https://bbs.kanxue.com/upload/attach/202501/857508_WPSYP5KYF2FFH2R.webp)
